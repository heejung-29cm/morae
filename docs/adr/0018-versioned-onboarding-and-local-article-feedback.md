# ADR-0018: 버전형 온보딩과 로컬 아티클 피드백

- 상태: Accepted
- 날짜: 2026-08-03

## 맥락

DMG를 처음 설치한 사용자는 메뉴 막대 앱의 존재, 관심사 설정,
Codex·Claude Hook, 알림 권한과 선택적 Jira 연결을 서로 다른 화면에서
찾아야 했습니다. 또한 추천 결과가 마음에 들지 않아도 다음 추천을
개선할 명시적 신호가 없었습니다.

## 결정

1. 첫 실행 시 현재 Space에 별도 온보딩 창을 열고 환영, 관심사,
   에이전트·알림, 선택적 Jira, 완료 순서로 안내합니다.
2. 완료 상태는 UserDefaults의 `onboarding.completedVersion`에 저장합니다.
   온보딩 계약이 크게 바뀌면 버전을 올려 기존 사용자에게 다시
   안내할 수 있습니다. 창을 닫기만 하면 완료로 기록하지 않습니다.
3. 설정의 일반 탭에서 온보딩을 언제든 다시 열 수 있습니다.
4. 아티클 카드에 `관심 없음`, `이 주제 더 보기`, `나중에 읽기`를
   제공합니다. 피드백과 분류 주제는 SQLite에만 저장합니다.
5. `관심 없음` URL은 이후 후보에서 제외합니다. `이 주제 더 보기`는
   동일 주제와 출처에 제한된 가중치를 더합니다. 기존 메타데이터 기반
   우선순위와 최근 30일 제한은 유지합니다.
6. 원문, 피드 본문, 사용자 행동 분석 이벤트를 외부로 보내지 않으며
   서버·계정·AI API를 추가하지 않습니다.

## 결과

- 신규 사용자는 별도 설정 창을 다시 찾지 않고 핵심 기능을 설정할 수
  있습니다.
- 추천은 사용자의 명시적 피드백으로 점진적으로 개인화되지만 기기 간
  동기화되지 않습니다.
- DB v7 migration으로 `articles.feedback`, `articles.topic`과 조회 index가
  추가됩니다.
- 선호가 누적되면 특정 주제나 출처가 편향될 수 있으므로 가중치에는
  상한을 둡니다. 피드백 전체 초기화 UI는 후속 범위입니다.

## 검토한 대안

- 원격 추천 프로필: 계정과 서버 운영, 개인정보 정책이 필요해 제외했습니다.
- 암묵적 클릭 추적만 사용: 사용자의 의도를 정확히 알기 어려워 읽음
  신호와 명시적 선호를 분리했습니다.
- Jira 연결을 필수화: Jira를 쓰지 않는 사용자도 있으므로 건너뛸 수 있는
  선택 단계로 유지했습니다.
