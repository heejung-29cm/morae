# ADR-0007: 원문 HTML의 로컬 본문 추출과 피드 폴백

- 상태: Superseded by ADR-0010
- 날짜: 2026-07-28
- 대체일: 2026-07-29

> 현재 MVP 결정은 [ADR-0010](0010-feed-metadata-only-article-recommendation.md)을 따릅니다. 아래 내용은 변경 이력을 보존하기 위한 이전 결정입니다.

## Context

RSS/Atom 피드는 사이트에 따라 전체 본문, 짧은 발췌 또는 제목과 링크만 제공합니다. 피드 내용만으로는 핵심 내용 3줄, 실무 중요성, 적용 예시를 안정적으로 생성하기 어렵습니다. 외부 본문 추출 서비스는 추가 비용과 개인정보 전송 경계를 만듭니다.

## Decision

- 추천 대상으로 선정한 아티클의 원문 HTML을 앱이 직접 가져옵니다.
- 본문 추출은 Mac 안에서 수행합니다.
- RSS/Atom 파싱에는 FeedKit, HTML DOM 파싱에는 SwiftSoup을 사용합니다.
- 두 패키지는 Swift Package Manager로 관리하고 `Package.resolved`를 저장소에 포함합니다.
- 추출에 성공하면 정제된 본문을 Claude API 입력으로 사용합니다.
- 추출에 실패하면 RSS/Atom의 본문 또는 요약으로 폴백합니다.
- 피드 내용도 없으면 Claude API를 호출하지 않고 제목, 출처, 원문 링크만 표시합니다.
- 원본 HTML은 DB나 로그에 저장하지 않고 추출 완료 후 폐기합니다.
- 스크립트 실행 없이 HTML을 데이터로 파싱하고 본문 길이 상한을 적용합니다.
- 외부 본문 추출 서비스는 사용하지 않습니다.

## Consequences

### Positive

- 축약 피드에서도 요약 품질을 유지할 수 있습니다.
- 외부 추출 서비스의 비용, 장애와 개인정보 전송을 피합니다.
- 피드 형식 변형과 malformed HTML을 직접 처리하는 코드 범위를 줄입니다.
- 추출 실패가 피드 폴백으로 격리됩니다.

### Negative

- 사이트별 HTML 구조 변화에 따라 추출 품질이 달라질 수 있습니다.
- 원문 요청으로 브리핑 지연과 네트워크 사용량이 늘어납니다.
- 접근 거부, 로그인 요구, 동적 렌더링 페이지는 처리하지 못할 수 있습니다.
- 본문 추출 라이브러리 또는 자체 휴리스틱의 유지보수가 필요합니다.
- FeedKit과 SwiftSoup의 버전 호환성과 보안 업데이트를 관리해야 합니다.

## Alternatives

- RSS/Atom 내용만 사용: 구현은 가장 단순하지만 축약 피드의 요약 품질이 요구사항에 미치지 못할 수 있어 제외했습니다.
- Foundation XMLParser와 자체 HTML parser: 외부 의존성은 줄지만 형식 변형과 손상된 문서 처리 범위가 커져 제외했습니다.
- 외부 Readability 서비스: 품질을 높일 수 있지만 비용과 추가 데이터 전송 때문에 제외했습니다.
- WebView 렌더링 후 추출: 동적 페이지 대응은 가능하지만 실행 비용과 보안 표면이 커 MVP에서 제외했습니다.
